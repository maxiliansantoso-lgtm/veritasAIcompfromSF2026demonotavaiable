# Veritas AI Hackathon 2026 — Working Repository

This repository is being prepared for the Veritas AI International High School Hackathon 2026.

## Current status

**This is a staging repository, not a completed project submission.** The only source materials available at the time of this initial publish were the official participant guide and the hackathon starter notebook. The completed AccentBridge project package and benchmark results were not available to publish.

No model evaluation scores are claimed here. Do not interpret this repository as evidence that a benchmark has been run or that a working robot system has been deployed.

## Project direction previously developed: AccentBridge

The proposed project explores multilingual speech recognition and a confirmation-first simulated robot voice-command interface. The planned comparison uses Whisper-small language detection versus forced language prompting on FLEURS English (US) and Indonesian test data.

Important scope limits:
- The planned comparison is between languages, not English accents.
- It uses read speech, not spontaneous robot commands.
- It does not establish fairness across accents or all speaker groups.
- The robot interaction is a software simulation, not a physical robot.
- Benchmark results must be run and reported honestly before being described as results.
