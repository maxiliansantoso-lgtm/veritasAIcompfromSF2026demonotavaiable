01 / The approach

Listen. Understand. Confirm.

Voice interfaces should make uncertainty visible. AccentBridge combines speech-recognition evaluation with a small, deliberately restricted robot-command vocabulary and a confirmation-first interaction.

01 — RECOGNISE

Turn speech into text

The research application uses Whisper-small to transcribe recordings, with automatic detection or a specified language setting.

02 — EVALUATE

Measure what changes

Compare transcription outputs with reference transcripts using word error rate (WER), and inspect substitutions, deletions and insertions.

03 — APPLY SAFELY

Keep a person in control

Only a recognised, unambiguous command can be proposed. A person reviews and confirms before the software simulator moves.

03 / Research method

Evidence before claims.

The benchmark scripts evaluate actual Whisper outputs against dataset transcripts. Results are generated only after a successful run; this website does not display fabricated accuracy scores.

Metric

Word Error Rate

WER = (S + D + I) / N

Substitutions, deletions and insertions divided by the number of words in the reference transcript. Lower WER indicates fewer word-level errors.

Dataset scope

Read speech, not every voice

The bundled FLEURS route compares English (US) and Indonesian. That is a language comparison, not an English-accent comparison. Read-speech results do not establish performance on spontaneous robot commands, noisy rooms, or every speaker.

Run the benchmark

Open the included QuickStart notebook in Google Colab and run the evaluation on the FLEURS test split.

Inspect real outputs

Review predictions.csv, summary.json and the generated WER plot. Check for inference errors and dataset counts.

Write up honestly

Generate the report from saved results. Do not claim scores until the run has completed and been checked.
