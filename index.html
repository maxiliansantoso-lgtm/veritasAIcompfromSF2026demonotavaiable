What this demo proves — and what it doesn't

This is a browser-based interaction prototype demonstrating multilingual command mapping and a human confirmation step. It does not run Whisper, compare automatic language detection with forced-language prompting, or provide benchmark results. Those experiments must be run and reported separately using the project's documented evaluation method.
